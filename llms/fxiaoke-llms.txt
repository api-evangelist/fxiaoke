# Fxiaoke (纷享销客)

> Fxiaoke is a Chinese enterprise SaaS company providing a connected, AI-driven "Agentic CRM" platform spanning marketing, sales, and customer service for 6,000+ enterprise customers. Its Open API v2 exposes CRM business objects (accounts, contacts, leads, opportunities, products, orders) and common services (approval workflows, directory/contact sync, business-data sync) as a JSON-over-HTTP POST RPC interface hosted at open.fxiaoke.com, authenticated with a self-built enterprise app (appId + appSecret + permanentCode) exchanged for an access token, plus a modern OAuth 2.1 (PKCE) authorization server.

## APIs

- [Fxiaoke Open API v2](https://developer.fxiaoke.com/openapi_v2/): CRM business-object and common-service API over JSON/HTTP POST; base host https://open.fxiaoke.com
